# Visual benchmark v1 contracts

`schema.json` is the versioned contract index. It names the JSONL record types
used by capture and annotation workers: `entity_capture`, `candidate`,
`visual_instance`, `mapping`, `label`, `adjudication`, and `rejection`.

`enums.json` is the canonical vocabulary for labels and rejection stages.
Workers must preserve `schema_version: "visual-benchmark-v1"`, stable IDs,
and provenance on every record. The schema is intentionally extensible so
capture code can add diagnostics without changing the identity of a record.

`benchmark-manifest.json` owns the immutable split and shard assignment. Its
`shards[].assignment_file` paths are under `shards/assignments/`; browser
capture evidence must use `captures/`, `captures.jsonl`, or another explicitly
declared evidence path and must never overwrite assignment files. The browser
worker's operational `manifest.json` is described separately by
`capture-manifest.schema.json`.

Assignment files generated by `scripts/visual-benchmark-shards.mjs` use the
additional `capture_assignment` record type. Assignment records are not
capture evidence and must not be mistaken for successful page captures.
