# Major brands 100 v1

See [`../../docs/major-brands-100-library-2026-09-14.md`](../../docs/major-brands-100-library-2026-09-14.md) for methodology, coverage, gaps, maintenance behavior, and validation.

The stable approved entrypoint is `manifest.json`. `sources.json` defines identity scope and aliases; `supplements.json` records targeted sources; `review-decisions.json` records rejected false positives. Assets are content-addressed and immutable. Timestamped `runs/` contain refresh evidence and change reports. `review/light.png` and `review/dark.png` are the visual review packet.
